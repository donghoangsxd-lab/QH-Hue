Thẩm định đồ án
Chuẩn bị file DXF
  1. Mở file CAD, chọn hatch các loại đất và lưu thành 2 file HT-ABC.dxf và QH-ABC.dxf (≤ 5 MB, trong đó ABC là mã tên đồ án).
  2. Tên layer hatch theo Thông tư 16/2025/TT-BXD. Một số lớp cần tách bằng hậu tố để quét nhanh:
    _MN / _TH / _THCS cho lớp Đất trường học;
    _CHO / _TM cho lớp Đất dịch vụ.
    VD: HT_DAT_HTXH_Truonghoc_MN; QHDH_DAT_Dichvu_Cho.
  3. Các lớp đối tượng đặt tên không đúng cần người dùng chọn thủ công.

Đối chiếu Phụ lục II Thông tư 16/2025: bốn gói NenDiaHinh, HienTrang, QuyHoach, MocGioi, tên lớp, kiểu hình và sáu trường bắt buộc. File đọc trên máy, không gửi đi.

Máy kiểm những gì
  1. Shapefile: 100 byte đầu file .shp, cả file .dbf và .prj. Phần tọa độ bỏ qua.
  2. GeoPackage: tên bảng và cột. File Geodatabase (.gdb): mới xác nhận có thư mục.
  3. Thiếu một chuyên đề trong Phần 3 chỉ là cảnh báo, vì danh mục đó là tham khảo.

Chọn đồ án quy hoạch đang điều chỉnh, gửi file DXF gồm ranh khu vực và các hatch lô đất mới trong ranh. Xem kết quả thẩm định, đồng ý thì bấm Nhập hồ sơ để ghi ranh điều chỉnh lên bản đồ quy hoạch (người dùng thường gửi Admin duyệt).

Hồ sơ điều chỉnh cục bộ gồm
  1. Ranh giới khu vực điều chỉnh: polygon hoặc polyline khép kín, tên layer có chữ RANH (VD RANH_DIEUCHINH).
  2. Hatch các lô đất trong phạm vi điều chỉnh, tên layer theo Thông tư 16/2025/TT-BXD (cùng quy ước với cân đối đất; trường học tách _MN / _TH / _THCS).
  3. (Không bắt buộc) File PDF scan Quyết định, bản vẽ điều chỉnh, dung lượng dưới 2 MB.

Ranh và lô cùng một file DXF, hệ VN-2000. Phạm vi phải nằm trong ranh đồ án đã chọn; chỉ tiêu cả đồ án tụt dưới 100% thì kết quả ghi Không đảm bảo.
